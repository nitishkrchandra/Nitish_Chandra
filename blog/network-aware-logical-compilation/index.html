Compilation and scheduling · November 2026 · 10 min read

From logical circuits to networked execution

Why mapping a logical circuit is more than minimizing remote gates

A logical quantum circuit is an abstract program. A real modular quantum computer has a limited number of encoded blocks, check ancillas, entanglement-generation ports and communication links. Translating the logical program into an executable fault-tolerant schedule requires an architecture-aware compilation stack.

The right level of compilation

Gate partitioning is a useful starting point, but a fault-tolerant instruction may be a complex gadget rather than a single physical gate. A code's supported logical gates must first be determined. A parity measurement or code-surgery operation has its own ancillary qubits, repeated measurements and decoding dependencies. These details determine what the network needs to deliver.

Five connected stages

01

Logical program: gate dependencies and target reliability.

02

Code-aware lowering: supported logical gadgets and ancillas.

03

Placement: assign encoded blocks and resources to QPUs.

04

Scheduling: allocate entanglement, communication ports and feedforward.

05

Evaluation: logical failure, completion time and resource usage.

The stages are coupled: placement changes remote-gate demand; scheduling changes memory waiting; waiting changes the error model and potentially the required code distance. This makes a one-way compiler that ignores physical timing inadequate for many distributed fault-tolerant workloads.

Network operations are not free

Our scheduling work investigated resource-limited network operations following partitioning, comparing constrained scheduling approaches with heuristic methods. A key lesson is that network dependencies and scarce resources must be represented explicitly. Recent work on network constraints in distributed FTQC likewise shows why finite entanglement rates and bandwidth competition matter for fault-tolerant execution.

Entanglement is a resource with a lifetime. Producing Bell pairs early can reduce stalls but increases storage exposure; generating them just in time can reduce aging but leave the computation waiting. Work on quantum-switch distillation policies illustrates how fidelity, throughput and waiting are interdependent.

Research outlook

I envision a compiler that outputs not only a schedule but an auditable reliability-and-resource report. The relevant objective is a tradeoff among logical error rate, makespan, communication load and ancillary resources, rather than simply minimizing the number of remote CNOTs.
